🔑 Cómo activar los cobros reales

La web ya está lista. Lo único que falta es pegar tus llaves de comercio (Flow para Chile y Wompi para Colombia) en las variables de entorno de Render.

1. ¿Por qué dice “faltan las credenciales de Wompi y de Flow Chile”?

Porque el sistema tiene 3 modos y ahora mismo está en el más seguro:

ModoCuándo ocurreQué hace
REALHay llaves de Flow y/o Wompi puestasCobra de verdad y mueve dinero real.
DEMONo hay llaves y DEMO_MODE=trueSimula el pago (solo para probar).
NO_CONFIGNo hay llaves y DEMO_MODE=falseNo cobra nada (error 503). No inventa pagos.

El aviso que viste es correcto y esperado: todavía no has pegado las llaves reales. La billetera muestra $0 porque, al no haber cobros reales, no hay dinero recaudado. En cuanto conectes las llaves y hagas un cobro real, el saldo aparecerá solo.

⚠️ Importante (legal): una web no puede custodiar el dinero de otras personas. El dinero lo custodia la pasarela (Flow en Chile, Wompi en Colombia, del grupo Bancolombia). La “billetera” de la web es solo una vista de ese dinero y sirve para ordenar la transferencia a tu Nequi.

2. Chile 🇨🇱 — Pasarela Flow (pago con código alfanumérico)

En Chile el cliente paga en efectivo con un código (Servipag / Sencillito). Eso lo da Flow.

2.1. Regístrate como comercio en Flow

  1. Entra a https://www.flow.cl y crea una cuenta de comercio.
  2. Necesitas RUT y tener el inicio de actividades al día en el SII (Flow lo exige). Si eres persona natural, tu RUT sirve.
  3. Completa la validación (datos del negocio y tu cuenta bancaria para depositarte lo recaudado).

2.2. Copia tus llaves

  1. Dentro de Flow, ve a Mis datos → API (o “Integración”).
  2. Copia API Key → FLOW_API_KEY y Secret Key → FLOW_SECRET_KEY.
  3. Para probar usa sandbox; para cobrar de verdad pon FLOW_ENV=production.
El “código alfanumérico” que le das al cliente lo genera Flow al crear el pago. El cliente no necesita RUT en la web; solo presenta el código donde paga.

3. Colombia 🇨🇴 — Pasarela Wompi (tarjeta → Nequi)

En Colombia el cliente paga con tarjeta débito/crédito Mastercard y el dinero llega a tu Nequi. Eso lo hace Wompi.

3.1. Regístrate como comercio en Wompi

  1. Entra a https://comercios.wompi.co y crea tu cuenta.
  2. Necesitas cédula colombiana y hacer el KYC (validación de identidad).
  3. Conecta tu cuenta de recaudo: aquí eliges tu Nequi.

3.2. Copia tus llaves

  • Llave pública → WOMPI_PUBLIC_KEY (empieza por pub_prod_)
  • Llave privada → WOMPI_PRIVATE_KEY (empieza por prv_prod_)
  • Secreto de integridad → WOMPI_INTEGRITY_SECRET
  • Secreto de eventos → WOMPI_EVENTS_SECRET
Para pruebas usa llaves pub_test_ / prv_test_ y WOMPI_ENV=sandbox. Para cobrar de verdad: WOMPI_ENV=production y llaves _prod_.

4. 💜 Pasar el saldo a Nequi (Wompi “Pagos a Terceros”)

Para que la web pueda dispersar (enviar) el dinero recaudado a tu Nequi automáticamente, Wompi te da acceso a “Pagos a Terceros” / Dispersiones. Esto se solicita al equipo de Wompi.

Cuando te lo habiliten, te entregan:

  • WOMPI_PAYOUTS_API_KEY — API Key de dispersiones
  • WOMPI_PAYOUTS_USER_PRINCIPAL_ID — User Principal ID
  • WOMPI_PAYOUTS_ACCOUNT_ID — Account ID

Y pones los datos de tu cuenta Nequi: NEQUI_PHONE, NEQUI_LEGAL_ID, NEQUI_NAME, NEQUI_EMAIL.

Si aún no tienes “Pagos a Terceros”, la billetera igual muestra el saldo, pero al dar “Transferir a Nequi” dirá “modo pendiente”. Es normal hasta que Wompi te habilite las dispersiones.

6. ✅ Cómo comprobar que quedó bien

  1. En el panel ya no aparece el aviso de “cobros sin activar”.
  2. En 🔑 Activación de cobros reales todo sale con ✅.
  3. Haz una prueba de cobro: Chile → verás el código; Colombia → prueba con una tarjeta de prueba de Wompi y el pago debe salir PAGADO.
  4. Cuando un cobro colombiano quede PAGADO, el saldo sube en la billetera y podrás pulsar “Transferir a Nequi”.

7. ❓ Preguntas frecuentes

¿Tengo que poner RUT a los clientes de Chile en la web?

No. El cliente chileno paga con el código que le da la web. El RUT solo lo necesitas tú para abrir la cuenta de comercio en Flow.

¿La web guarda el dinero?

No. Lo custodia la pasarela (Flow/Wompi). La web solo muestra el saldo y ordena la transferencia a tu Nequi.

¿Puedo probar sin llaves reales?

Sí: con DEMO_MODE=true la web simula el pago. Para cobrar de verdad, pon las llaves y DEMO_MODE=false.

¿Y si solo tengo Flow (Chile) y todavía no Wompi (Colombia)?

La web funciona igual: Chile cobra de verdad y Colombia queda “sin activar” hasta que pegues las llaves de Wompi. Cada país se activa por separado.
